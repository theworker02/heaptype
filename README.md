# heaptype

Heap validation gates for type inputs before they hit prod.

**Site:** https://theworker02.github.io/heaptype/

## Install / run

```bash
git clone https://github.com/theworker02/heaptype.git
cd heaptype
node src/cli.js
node --test
```
